# Dump Updates

Public Sparkle update feed for Dump.

- Feed: https://myattj.github.io/dump-updates/appcast.xml
- Release assets: https://github.com/myattj/dump-updates/releases

The DMG is published as a GitHub Release asset. `appcast.xml` points Sparkle at
that asset and is signed with the Sparkle EdDSA key stored in Josh's Keychain.
